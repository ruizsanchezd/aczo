# Colores

Toda la paleta vive como variables CSS en `src/app/globals.css`. Los componentes nunca usan
colores directos: siempre tokens semánticos (`bg-background-low`, `text-content-mid`…), de modo
que un cambio en el token repinta todo el prototipo.

El producto va siempre en **modo claro** (lo fuerza `data-theme="light"`), así que lo que ves
abajo es ese modo. Lo que **sí cambia** si algún día se activa el oscuro: contenido, fondos,
bordes y los fondos suaves de feedback. Lo que **no cambia** entre modos (así está en el Figma,
no es un olvido): la familia `highlight`, la paleta `extended`, los colores fuertes de feedback y
los `content-always-*` / `background-always-*`.
